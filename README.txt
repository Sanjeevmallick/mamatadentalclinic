MAMATA DENTAL CLINIC - WEBSITE
=================================

This version recreates the supplied poster as a REAL responsive webpage.
The poster itself is NOT used as the page background.

Files:
- index.html
- style.css
- script.js
- assets/

Features:
- Responsive mobile/desktop design
- Click-to-call phone numbers
- Google Maps branch buttons
- Service information popups
- Appointment form -> WhatsApp
- Facebook / Instagram buttons
- No broken image paths

GitHub Pages:
Upload ALL files/folders keeping this structure, then enable GitHub Pages from
Settings -> Pages -> Deploy from branch -> main -> /root.
